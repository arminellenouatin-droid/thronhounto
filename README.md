# THRON HOUNTO — Plateforme SaaS de la Communauté Thron

Bienvenue sur le dépôt officiel du projet **THRON HOUNTO** (Version 1.0 - Lot 0 & Lot 1 MVP).

THRON HOUNTO est un SaaS souverain dédié aux organisations de la communauté spirituelle Thron : Courants, Lignées et Temples (Hountos). Il fédère dans une application mobile first et PWA :
- L'arbre généalogique spirituel tactile avec navigation descendante et ascendante
- Le réseau social communautaire (**Togoun**)
- Le fil vidéo rituel et d'enseignements (**Tognon**)
- La messagerie instantanée avec étiquette en ligne (**Atinsa**)
- La marketplace de produits et services spirituels certifiés (avec commission de 8%)
- Les tontines et cotisations communautaires
- Le portefeuille électronique (Wallet) avec grand livre à double entrée
- La boîte à outils complète de gestion spirituelle et financière

## 🛠️ Stack Technique
- **Framework** : Next.js 15 (App Router, React 19, TypeScript)
- **Styling & Design System** : Tailwind CSS, Thron Sacred Palette (Bleu Royal, Or Sacré, Blanc Cassé, Anthracite)
- **Base de Données** : Neon PostgreSQL Serverless (`@neondatabase/serverless`)
- **Hébergement & Déploiement** : Netlify / GitHub
- **PWA** : Web App Manifest, Service Worker ready, Touch targets 44px+
